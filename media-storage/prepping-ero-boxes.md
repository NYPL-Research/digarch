# ReCAP Shipping
Intro to ReCAP Shipping, what and where it is.

## Legacy Electronic Records Originals Boxes
ERO boxes 13-14 at LSC and in SPEC were created using the legacy system, CMS.  
Carriers currently in those boxes are documented in the media log view of SPEC.  
Document new carriers added to these boxes in SPEC.  

## Converting Boxes to Electronic Records Originals 
When a box of digital carriers is full and exists in a collection you can  
convert the box object record in SPEC to the Electronic Records Originals collection.  
* Navigate to the box object record in SPEC.  
* Select View All /Edit / Add to the right of References.  
* Select Add Reference.  
* Select Type CMS collection id from dropdown.  
* Select search and enter 23281.  
* Select Electronic Records Originals.  
* Select Basic Fields tab to the left in the same window as the References tab. 
* Keep useful information like carrier count in the title.  
* Delete previous collection name if in the title.  
* Enter ID or Sequence number, the next available box number for ERO.  

## Adding New Boxes to Electronic Records Originals
When a box of digital carriers is full and doesn't have a barcode you can barcode it  
and add an object record for the box in the Electronic Records Originals collection.  

### Cataloging
Before shipping, boxes must be added to the Electronic Records Originals collection  
in Sierra. 
* Add boxes to the ERO collection in Sierra.
